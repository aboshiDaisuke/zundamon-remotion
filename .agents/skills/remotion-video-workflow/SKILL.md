# Remotion キャラクター解説動画 制作ワークフロー

ずんだもんや四国めたんを活用したハイクオリティなRemotion解説動画を制作・更新するための標準手順書（ランブック）です。

---

## 1. 全体アーキテクチャ・必須素材・外部サービス一覧

本動画制作システムが依存・活用している各種サービス、ツール、アセット素材の一覧です。

### 外部サービス・開発環境
- **動画合成フレームワーク**: **Remotion (v4.0+)**
  - React 18 / TypeScript / Node.js
  - レンダリングコマンド: `npx remotion render ...` / 静止画プレビュー: `npx remotion still ...`
- **音声合成エンジン**: **VOICEVOX**
  - 無料・商用利用可能な音声合成ソフトウェア（要ローカル起動 `http://127.0.0.1:50021`）
  - スピーカーID:
    - **ずんだもん**: ノーマル(3)、あまあま(1)、ツンツン(7)、セクシー(5)
    - **四国めたん**: ノーマル(2)、あまあま(0)、ツンツン(6)、セクシー(4)
  - クレジット表記: 「VOICEVOX:ずんだもん」「VOICEVOX:四国めたん」
- **自動化環境**: **Python 3**
  - `scripts/generate_dual_audio.py`（VOICEVOX API連携、WAV生成、フレーム数自動集計）
  - `scripts/extract_psd_layers.py`（PSD立ち絵パーツ抽出用）

### アセット素材とクレジット表記規約
- **フォント**: **けいフォント**
  - 格納先: `public/fonts/keifont.ttf`
  - 配布元: フォントな（MODI工場様）/ 商用利用可
  - 必ず `src/load-font.ts` の `useEnsureKeiFont()` により `delayRender` でロード完了を同期待機すること。
- **キャラクター立ち絵**: **坂本アヒル様 立ち絵素材**
  - 素材ファイル: ルート直下 `ずんだもん立ち絵素材2.3.psd` / `四国めたん立ち絵素材2.1.psd`
  - 展開パーツ: `public/characters/zundamon/`, `public/characters/metan/`
  - クレジット表記: 「立ち絵: 坂本アヒル様」
- **背景イラスト**: **みんちりえ（フリー背景イラスト素材）**
  - 格納先: `public/backgrounds/minchirie_*.jpg`
  - 配布元: https://minchirie.info/ （商用利用可・クレジット表記推奨）
  - 画面右下隅またはクレジット欄に「背景: みんちりえ」を表示。
- **BGM**: **しゃろう様「2:23 AM」**
  - 格納先: `public/audio/bgm.mp3`
  - 配布元: DOVA-SYNDROME / YouTube
  - クレジット表記: 「BGM: しゃろう」
- **解説カード用画像**:
  - 生成AIイラストおよび公式広報画像（`public/images/card_scene*.jpg`, `public/images/anime/*.jpg`）
- **データ管理**: `src/dual_scene_data.json`（各シーンのセリフ、表示情報、音声ファイルパス、durationInFrames、startFrameを自動集計）

## 2. 制作手順（ステップ・バイ・ステップ）

### Step 1: 台本・構成の設計（Script & Structure）
1. **ネタの掛け合いコント化**:
   - ユーザーから提供されたネタ（地域あるある・自虐ネタなど）は、単発の1台詞で終わらせず、ずんだもんとめたんの**3〜5往復の掛け合いコント**に展開する。
   - 例（神戸ナンバーの場合）:
     - ずんだもん（提起・ビビる） ➔ めたん（都会のセレブと勘違い） ➔ ずんだもん（正体は淡路島民と暴露） ➔ めたん（玉ねぎ畑なのにずるいとツッコミ） ➔ ずんだもん（激しいコンプレックスのオチ）
2. **シーンデータの定義**:
   - `scripts/generate_dual_audio.py` 内の `SCENES` リストにシーンを定義。
   - `topic_num`（トピック連番）、`speaker`（2: めたん, 3: ずんだもん）、`text`（表示用字幕）、`voice_text`（ひらがな/カタカナ発音用）、`topic`（大見出し）、`sub`（右上テロップ用）、`points`（解説3行）、`image`、`emotion` などを設定。

---

### Step 2: VOICEVOX 音声合成とメタデータ自動更新
以下のコマンドを実行し、音声合成とシーンデータの再計算を一括で行う：

```bash
python3 scripts/generate_dual_audio.py
```

- **処理内容**:
  1. VOICEVOXローカルAPIへリクエスト送信（話速: 1.16〜1.18倍、抑揚: 1.15〜1.20）。
  2. `public/audio/` 配下に各シーンの `.wav` を保存。
  3. 各音声の秒数からフレーム数（30fps換算）および累計開始フレーム（`startFrame`）を自動算出し、`src/dual_scene_data.json` を更新。
  4. 合計フレーム数（`totalFrames`）を更新し、`src/Root.tsx` の Composition と自動同期。

---

### Step 3: UIレイアウトとデザイン基準の確認
要素ごとの配置ルール（被りゼロ基準）を遵守する：

1. **画面最上部（y: 8px〜60px）: ヘッダーバー**
   - 左側: 公式広報バッジ（24px）
   - 右側: **番組風金枠コーナーテロップ**（20px けいフォント、枠線 `#ffd54f`、深緑グラデーション）
2. **画面中央（y: 70px〜680px, width: 860px）: 中央解説カード**
   - 上部: 中央揃えカテゴリバッジ（16px）＋ メイン大見出し（**38px けいフォント**、白フチ＆シャドウ）
   - 中央: メインイラスト（高さ約385px、角丸＆枠線、Ken Burnsズーム）
   - 下部: 解説ポイント3行（**24px けいフォント**、丸型ナンバリングバッジ❶❷❸、左端6pxアクセントライン）
3. **画面左右（x: 40px / x: 1450px）: 立ち絵キャラクター**
   - 左: ずんだもん（話者時にバウンド、セリフ連動口パク）
   - 右: 四国めたん（話者時にバウンド、セリフ連動口パク）
   - 頭上に話者吹き出しバッジ（ずんだもん: 緑、めたん: ピンク）
4. **画面下部（y: 930px〜1040px）: 字幕バー**
   - 中央カード下端から150px以上の安全余白
   - 32〜34px けいフォント、話者色分け（ずんだもん: 濃緑、めたん: 濃紫/ピンク）

---

### Step 4: 静止画による自律レンダリング検証（Still Check）
動画全体をレンダリングする前に、代表フレームの静止画を出力して目視・自己点検を行う：

```bash
# 例: シーンごとの静止画確認
npx remotion still src/index.ts DualExplainer out/preview_scene.png --frame=<TargetFrame>
```

- **点検項目**:
  - [ ] けいフォントが適用されているか（角ゴシックにフォールバックしていないか）
  - [ ] 右上テロップと中央カードが被っていないか
  - [ ] 解説文字（24px）が読みやすく見切れていないか
  - [ ] 話者キャラクターの口パク・表情・吹き出しバッジがセリフと整合しているか

---

### Step 5: 動画本編のレンダリング（Render Video）
検証完了後、Remotionで本編動画をレンダリングする：

```bash
# 10コアMacでの推奨並列数（--concurrency=8）
npx remotion render src/index.ts DualExplainer out/zundamon_metan.mp4 --concurrency=8
```

- ※ 部分プレビューを出力してユーザーに見せる場合は、必ず「これは確認用の部分プレビュー動画です」と明記すること。

---

### Step 6: 成果物ディレクトリ（`out/`）のクリーンアップ
制作完了時、中間生成物（テスト画像、テスト音声、旧動画）を整理し、ユーザーに納品する最新動画ファイルのみを残す：

```bash
find out -maxdepth 1 -type f ! -name "zundamon_metan.mp4" -delete
```

## 3. よくあるトラブルと解決策

| 現象 | 原因 | 解決策 |
|---|---|---|
| **フォントが角ゴシックになる** | Chromiumのフォントロード遅延 | `src/load-font.ts` の `useEnsureKeiFont()` をコンポーネントルート（`DualExplainer.tsx`）で確実に呼び出す |
| **中央カードと右上テロップが被る** | カード内右上にサブタイトルを押し込んでいる | `HeaderBar.tsx` の右端に独立したテロップ枠を新設し、カード内は中央揃えにする |
| **動画が短く見える・話が消えたと誤認される** | 部分プレビューをそのまま提示した | 全編動画（`zundamon_metan.mp4`）をレンダリングして渡すか、プレビューである旨を明記する |
| **VOICEVOXの読み間違い** | 固有名詞や漢字の読み | `voice_text` でひらがな・カタカナ・読点（ポーズ）を指定して調整する |
