# ずんだもん・四国めたん動画制作

## 編集元と成果物

- 台本・番組名・話題・画像・二人の表情: **`content/episode.json`**。
- 自動生成: `src/dual_scene_data.json`（尺・音声・口パク含む）、`src/dual_audio_cache.json`。直接編集しない。
- 座標: `src/layout.ts`。配色・文字サイズ: `src/theme.ts`。
- 全編: `out/zundamon_metan.mp4`。静止画一覧: `out/review/index.html`。
- セリフのスキーマ・表情一覧・依頼文はプロジェクトルートの `docs/AI_PROMPT_GUIDE.md` を参照。

## 制作手順

1. 既存ファイルとユーザーの変更を確認し、`npm run doctor` で素材・環境を確認する。
2. `content/episode.json` を編集する。新しい地域ネタ・あるあるは1話題3〜5往復の掛け合いに展開する。見出しは短く、要点は各26文字程度以内の3行を目安にする。
3. 新しい音声が必要ならVOICEVOX起動後 `npm run audio:dual`。既存音声で画面だけ更新するなら `npm run sync`。後者は未生成・変更済みの音声を検出すると停止する。
4. `npm run check`、`npm run preview`。全セリフ・エンディング・「おしまい」の静止画を目視する。字幕のページ切り替えや話者交代はStudioでも確認する。
5. 検証後 `npm run render`。本編に約6.7秒のエンディングが自動で付く。
6. 最新完全版を明示して渡す。短尺だけの場合は「○○シーンの確認用プレビューです。全編動画は別でレンダリングします」と伝える。

`npm run video` は音声・検査・静止画出力・全編書き出しを連続実行する補助コマンドで、目視確認の代わりにはならない。`npm run clean` は既知の中間プレビューだけを整理する。ユーザーの別動画や関係のないファイルを削除しない。

## 台本と音声の注意

- 一つのlineは一人の話者。`speaker` は `zundamon` / `metan`。両者の台詞を一つに結合しない。
- 表示は `text`、読みは `voiceText`。読みを別指定した発言を変更するときは両方を更新する。
- 読み間違いしやすい固有名詞はカナ指定。話速1.15〜1.18、抑揚1.15〜1.20を基準とする。
- 画像や表情の変更は音声の再合成を要求しない。変更した読み・話速・話者のみ合成される。
- 話者交代をシーンID別の固定秒数で実装しない。WAVから計測した尺を使う。
- 口パクはPCM音量を用い、無音では閉じる。まばたきは専用差分。表情はlineの `expressions` で二人それぞれ指定する。
- 長い字幕は33pxのまま最大2行でページ分割。ページ時間は文字数配分なので、正確なタイミングが必要な長文はlineを分ける。

## デザイン基準

1920×1080。タイトルセーフは x 96〜1824 / y 54〜1026、キャラは x 67〜1853。

- ヘッダー y 54〜118: 左は二段の番組名、右は金枠＋深緑の独立コーナーテロップ。
- 中央カード y 150〜760、幅860: カテゴリ16px、大見出し38px、画像860×385、要点24pxを最大3行。
- 同じ話題の話者交代ではカードの入場を繰り返さない。進行表示はカードと字幕の間の独立領域。
- キャラは左右に配置し足元はy 900以内。話し始めの小さなバウンドは一度。頭上の名前札を置かない。
- 字幕 y 910〜1020、幅1380、33px。話者タグを枠内に収め、ずんだもんは緑、四国めたんはピンク。
- 背景はみんちりえ素材＋ぼかし＋ベール。余分な装飾を加えない。
- `useEnsureKeiFont()` でフォント読込完了後に描画する。失敗時はレンダリングを停止する。
- 見出し・要点が長すぎる場合はエラーになる。小さく縮めず文章を短くする。

## カードイラストの作り方

各話題1枚、`public/images/cards/topicNN_<内容>.jpg`、1720×770（2.23:1）。

共通プロンプト:

> 解説動画の中央カード用。日本の明るいTVアニメ背景美術風。くっきりした線、セル塗り、柔らかな光、上品な彩度。横長2.23:1。文字・ロゴ・数字・ウォーターマーク・人物キャラクターを描かない。主要被写体は中央に配置する。内容:（具体的な情景）

画像生成ツールの手順に従って作り、切り抜き後の構図・不要な文字・絵柄の統一を確認する。差し替えは **`topics[].image` だけ**を編集して `npm run sync`。Pythonと生成JSONの二重編集は不要。

## 必要素材

- VOICEVOX: `http://127.0.0.1:50021`。ずんだもんID3、四国めたんID2。
- フォント: `public/fonts/keifont.ttf`。
- 立ち絵: `public/characters/`。坂本アヒル様の対応PSD（ずんだもん2.3 / 四国めたん2.1）をルートに置き `npm run characters` で口パク・まばたき差分を抽出。Pythonの `psd-tools` と `Pillow` が必要。別PSDはレイヤー対応が必要。
- 背景: `public/backgrounds/minchirie_*.jpg`。
- BGM: `public/audio/bgm.mp3`（しゃろう「2:23 AM」）。
- クレジット: VOICEVOX:ずんだもん、VOICEVOX:四国めたん、立ち絵素材:坂本アヒル様、けいフォント、背景:みんちりえ、BGM:しゃろう。

新しい素材は公式配布元の利用条件に従う。過剰なクローリングをしない。素材を変更したらエンディングのクレジットも合わせて直す。
