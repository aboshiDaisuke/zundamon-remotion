# Remotion キャラクター解説動画 制作ワークフロー

ずんだもんや四国めたんを活用したハイクオリティなRemotion解説動画を制作・更新するための標準手順書（ランブック）です。

---

## 1. 全体アーキテクチャ・必須素材・外部サービス一覧

本動画制作システムが依存・活用している各種サービス、ツール、アセット素材の一覧です。

### 外部サービス・開発環境
- **動画合成フレームワーク**: **Remotion (v4.0+)**
  - React 18 / TypeScript / Node.js
  - レンダリングコマンド: `npx remotion render ...` / 静止画プレビュー: `npx remotion still ...`
- **音声合成エンジン**: **VOICEVOX**
  - 無料・商用利用可能な音声合成ソフトウェア（要ローカル起動 `http://127.0.0.1:50021`）
  - スピーカーID:
    - **ずんだもん**: ノーマル(3)、あまあま(1)、ツンツン(7)、セクシー(5)
    - **四国めたん**: ノーマル(2)、あまあま(0)、ツンツン(6)、セクシー(4)
  - クレジット表記: 「VOICEVOX:ずんだもん」「VOICEVOX:四国めたん」
- **自動化環境**: **Python 3**
  - `scripts/generate_dual_audio.py`（VOICEVOX API連携、WAV生成、フレーム数自動集計）
  - `scripts/extract_psd_layers.py`（PSD立ち絵パーツ抽出用）

### アセット素材とクレジット表記規約
- **フォント**: **けいフォント**
  - 格納先: `public/fonts/keifont.ttf`
  - 配布元: フォントな（MODI工場様）/ 商用利用可
  - 必ず `src/load-font.ts` の `useEnsureKeiFont()` により `delayRender` でロード完了を同期待機すること。
- **キャラクター立ち絵**: **坂本アヒル様 立ち絵素材**
  - 素材ファイル: ルート直下 `ずんだもん立ち絵素材2.3.psd` / `四国めたん立ち絵素材2.1.psd`
  - 展開パーツ: `public/characters/zundamon/`, `public/characters/metan/`
  - クレジット表記: 「立ち絵: 坂本アヒル様」
- **背景イラスト**: **みんちりえ（フリー背景イラスト素材）**
  - 格納先: `public/backgrounds/minchirie_*.jpg`
  - 配布元: https://minchirie.info/ （商用利用可・クレジット表記推奨）
  - 画面右下隅またはクレジット欄に「背景: みんちりえ」を表示。
- **BGM**: **しゃろう様「2:23 AM」**
  - 格納先: `public/audio/bgm.mp3`
  - 配布元: DOVA-SYNDROME / YouTube
  - クレジット表記: 「BGM: しゃろう」
- **解説カード用画像**:
  - 生成AIイラスト（`public/images/cards/topicNN_<内容>.jpg`、1720×770）。作り方は「Step 2.5」を参照。
- **データ管理**: `src/dual_scene_data.json`（各シーンのセリフ、表示情報、音声ファイルパス、durationInFrames、startFrameを自動集計）

## 2. 制作手順（ステップ・バイ・ステップ）

### Step 1: 台本・構成の設計（Script & Structure）
1. **ネタの掛け合いコント化**:
   - ユーザーから提供されたネタ（地域あるある・自虐ネタなど）は、単発の1台詞で終わらせず、ずんだもんとめたんの**3〜5往復の掛け合いコント**に展開する。
   - 例（神戸ナンバーの場合）:
     - ずんだもん（提起・ビビる） ➔ めたん（都会のセレブと勘違い） ➔ ずんだもん（正体は淡路島民と暴露） ➔ めたん（玉ねぎ畑なのにずるいとツッコミ） ➔ ずんだもん（激しいコンプレックスのオチ）
2. **シーンデータの定義**:
   - `scripts/generate_dual_audio.py` 内の `SCENES` リストにシーンを定義。
   - `topic_num`（トピック連番）、`speaker`（2: めたん, 3: ずんだもん）、`text`（表示用字幕）、`voice_text`（ひらがな/カタカナ発音用）、`topic`（大見出し）、`sub`（右上テロップ用）、`points`（解説3行）、`image`、`emotion` などを設定。

---

### Step 2: VOICEVOX 音声合成とメタデータ自動更新
以下のコマンドを実行し、音声合成とシーンデータの再計算を一括で行う：

```bash
python3 scripts/generate_dual_audio.py
```

- **処理内容**:
  1. VOICEVOXローカルAPIへリクエスト送信（話速: 1.16〜1.18倍、抑揚: 1.15〜1.20）。
  2. `public/audio/` 配下に各シーンの `.wav` を保存。
  3. 各音声の秒数からフレーム数（30fps換算）および累計開始フレーム（`startFrame`）を自動算出し、`src/dual_scene_data.json` を更新。
  4. 合計フレーム数（`totalFrames`）を更新し、`src/Root.tsx` の Composition と自動同期。

---

### Step 2.5: カードイラストの作り方（新しい話題を足したとき・画像を作り直すとき）
画像生成が使えるAI（codex CLI、ChatGPT、Antigravity等）で、話題ごとに1枚作る。

1. **プロンプトの共通部分**（全話で同じ文面を使い、絵柄を揃える）:
   ```text
   画像を1枚生成して、このフォルダに card.png という名前で保存してください。
   【用途】解説動画の中央カードに入れるイラスト。最終的に 2.23:1（1720x770）に中央でトリミングされる。
   【サイズ】横長 1536x1024 で生成。主要な被写体は縦方向の中央 2/3 の帯に収め、上下それぞれ1/6は切れても問題ない構図にする。
   【絵柄】日本の明るいTVアニメの背景美術風。くっきりした線、セル塗り＋やわらかい光。彩度はやや高めだが上品。写真風・リアル寄りにしない。
   【禁止】文字・看板の文字・ロゴ・ウォーターマーク・数字・ナンバープレートの文字を一切描かない。アニメキャラクターの人物は描かない（群衆は小さく、顔の細部なしならOK）。
   【内容】（ここに話題ごとの情景を具体的に書く。何が・どこに・どの時間帯か・構図）
   ```
   - 文字を描かせないのは、見出しと解説文をカード側で出すため（AIが描く文字は崩れやすい）。
   - キャラクターを描かせないのは、ずんだもん・めたんが画面の左右に常にいるため。
2. **codex CLI での生成例**（話題ごとにフォルダを分け、並列で実行できる）:
   ```bash
   mkdir -p gen/s07 && cd gen/s07 && codex exec --skip-git-repo-check - < prompt.txt > log.txt 2>&1
   ```
3. **トリミングと保存**: 中央を 2.23:1 で切り抜き、1720×770 のJPG（品質90）で `public/images/cards/topicNN_<内容>.jpg` に保存する。
4. **検品**（全部やってからユーザーに見せる）:
   - 切り抜き後の全話を縮小一覧に並べ、絵柄・明るさが揃っているか見る。
   - 文字やロゴが混ざっていないか、人物の手・指が崩れていないかを拡大して確認する。
   - ダメな1枚はプロンプトを直してゼロから作り直す（画像処理で直さない）。
5. **パスの更新**: `scripts/generate_dual_audio.py` の `SCENES` と `src/dual_scene_data.json` の両方で `image` を差し替える（片方だけだと `npm run audio:dual` の再実行で古い画像に戻る）。

### Step 3: UIレイアウトとデザイン基準の確認（セーフゾーン）
座標の正は `src/layout.ts`。レイアウトを変えるときはこのファイルの数値だけを直し、コンポーネントに直書きしない。

0. **セーフゾーン（1920×1080）**
   - 文字要素（テロップ・見出し・字幕・クレジット）: **タイトルセーフ x 96〜1824 / y 54〜1026** の内側
   - キャラクター: **アクションセーフ x 67〜1853** の内側
1. **ヘッダー（y 54〜118）** — `HeaderBar.tsx`
   - 左: 番組名テロップ（2段: 上15px「徳島県徳島市 シティプロモーション」／下30px「〜阿波おどりと水都のまち〜」、左端に深緑バー）
   - 右: **番組風金枠コーナーテロップ**（30px けいフォント、枠線 `#ffd54f`、深緑グラデーション）。1行に収まる長さ（24文字程度まで）にする
2. **中央解説カード（y 150〜760, width 860px）** — `DualTopicCard.tsx`
   - 白いカード1枚に、カテゴリバッジ（16px）＋ 大見出し（**38px けいフォント**）
   - イラスト（860×385px、枠いっぱいに表示、ゆっくりズーム）
   - 解説ポイント3行（**24px けいフォント**、丸型ナンバリング❶❷❸、左端6pxの深緑バー）
   - 同じ `topic_num` が続くシーン（例: 3_1〜3_5）では入場アニメを繰り返さない（`DualExplainer.tsx` の `topicOffsets`）
3. **立ち絵キャラクター** — `DualCharacters.tsx`
   - 左: ずんだもん（x 70〜520）／右: 四国めたん（x 1400〜1850）、足元は y 900 まで（字幕に重ねない）
   - 喋り出しに1回だけピョコッと跳ねる。常時の上下揺れはしない。話していない側は少し暗くする
   - 頭上の名前札は付けない（話者は字幕の話者タグで示す）
   - 表情は `topic_num` 単位で決める（シーン番号ではなく話題番号で `switch` する）
4. **字幕バー（y 910〜1020, width 1380px）** — `DualSubtitleBar.tsx`
   - 中央カード下端から150px以上の余白
   - 33px けいフォント、話者タグ（ずんだもん: 緑、めたん: ピンク）
5. **背景** — `Background.tsx`
   - みんちりえ素材をぼかし＋薄いベールだけにする。ボケ玉・波・ドット柄などの装飾は足さない
   - 「背景：みんちりえ」はタイトルセーフ内の右下に表示
6. **エンディング（約6.7秒）** — `DualOutro.tsx`
   - キャラ登場＋紙吹雪 → 「ご視聴ありがとうございました！」（2行） → サブ文 → クレジット → アイリスアウト → 「おしまい」
   - 尺は `src/Root.tsx` で `totalFrames + OUTRO_FRAMES` と加算する。話題を足してもエンディングは自動で最後に付く

---

### Step 4: 静止画による自律レンダリング検証（Still Check）
動画全体をレンダリングする前に、代表フレームの静止画を出力して目視・自己点検を行う：

```bash
# 例: シーンごとの静止画確認
npx remotion still src/index.ts DualExplainer out/preview_scene.png --frame=<TargetFrame>
```

- **点検項目**:
  - [ ] けいフォントが適用されているか（角ゴシックにフォールバックしていないか）
  - [ ] 右上テロップと中央カードが被っていないか
  - [ ] 解説文字（24px）が読みやすく見切れていないか
  - [ ] 話者キャラクターの口パク・表情・字幕の話者タグがセリフと整合しているか
  - [ ] すべての文字がタイトルセーフ（x 96〜1824 / y 54〜1026）の内側にあるか（静止画に枠線を重ねて確認すると確実）
  - [ ] キャラの足が字幕バーに重なっていないか
  - [ ] エンディング（最後の約6.7秒）の中盤と「おしまい」画面も確認したか

---

### Step 5: 動画本編のレンダリング（Render Video）
検証完了後、Remotionで本編動画をレンダリングする：

```bash
# 10コアMacでの推奨並列数（--concurrency=8）
npx remotion render src/index.ts DualExplainer out/zundamon_metan.mp4 --concurrency=8
```

- ※ 部分プレビューを出力してユーザーに見せる場合は、必ず「これは確認用の部分プレビュー動画です」と明記すること。

---

### Step 6: 成果物ディレクトリ（`out/`）のクリーンアップ
制作完了時、中間生成物（テスト画像、テスト音声、旧動画）を整理し、ユーザーに納品する最新動画ファイルのみを残す：

```bash
find out -maxdepth 1 -type f ! -name "zundamon_metan.mp4" -delete
```

## 3. よくあるトラブルと解決策

| 現象 | 原因 | 解決策 |
|---|---|---|
| **フォントが角ゴシックになる** | Chromiumのフォントロード遅延 | `src/load-font.ts` の `useEnsureKeiFont()` をコンポーネントルート（`DualExplainer.tsx`）で確実に呼び出す |
| **中央カードと右上テロップが被る** | カード内右上にサブタイトルを押し込んでいる | `HeaderBar.tsx` の右端に独立したテロップ枠を新設し、カード内は中央揃えにする |
| **動画が短く見える・話が消えたと誤認される** | 部分プレビューをそのまま提示した | 全編動画（`zundamon_metan.mp4`）をレンダリングして渡すか、プレビューである旨を明記する |
| **VOICEVOXの読み間違い** | 固有名詞や漢字の読み | `voice_text` でひらがな・カタカナ・読点（ポーズ）を指定して調整する |
| **テロップが画面端で切れる／窮屈** | セーフゾーン外に配置している | `src/layout.ts` の `SAFE` を基準に配置する。長い番組名は2段にする |
| **カード画像の文字が崩れる** | 生成AIに文字を描かせた | 画像には文字を入れず、見出し・解説はカード側のテキストで出す |
| **audio:dual 後に画像が古いものに戻る** | `generate_dual_audio.py` の `SCENES` を更新していない | JSONとスクリプトの両方の `image` を更新する |
