# 掛け合い動画の制作ガイド

## 依頼文のテンプレート

```text
テーマ: ○○
視聴者: 初めてこの話題を知る人
希望の長さ: 約3分
出演: ずんだもん（素朴な疑問・ボケ）、四国めたん（解説・ツッコミ）
雰囲気: 明るく、テンポよく、相手を見下す表現は避ける

content/episode.json を編集して制作してください。
1話題につき3〜5往復。冒頭は気になる疑問、最後は覚えてほしい一言。
見出しは20文字程度以内、要点は各26文字程度以内の3行。
同じ話題の情報はtopicsに一度だけ書き、linesで会話を続けてください。
音声合成後に全シーン・エンディングの静止画を確認し、全編を書き出してください。
```

## 編集の入口

編集元は `content/episode.json` 一つ。`src/dual_scene_data.json` と `src/dual_audio_cache.json` は生成物です。Pythonスクリプトに台本を書き込みません。

- `program.eyebrow`: 左上の小さなシリーズ名（15px）
- `program.title`: 左上の番組名（30px、目安17文字以内）
- `program.label`: カードのシリーズ表記
- `program.outro`: 締めのメッセージ（目安24文字以内）
- `topics[].title`: 中央の大見出し（38px）
- `topics[].corner`: 右上のコーナーテロップ（30px、目安28文字以内）
- `topics[].points`: 要点を1〜3行（24px）
- `topics[].image`: `public/` からの画像パス
- `topics[].background`: 背景の画像パス

文字数は目安です。けいフォントで実測し、枠を超える見出し・要点はレンダリングを停止します。小さく縮めて詰め込まず、文を短くしてください。

## セリフの例

既存の `topics[].lines` に、次の形式で追加できます。

```json
{
  "id": "topic01_zunda_01",
  "speaker": "zundamon",
  "text": "どうして徳島では、電車じゃなくて\n「汽車」って呼ぶのだ？",
  "voiceText": "どうしてトクシマでは、電車じゃなくて、きしゃって呼ぶのだ？",
  "expressions": {"zundamon": "explain", "metan": "proud"}
}
```

- `id`: 重複しない英数字・`_`・`-`。
- `speaker`: `zundamon` / `metan`。**一つのセリフは必ず一人**。交代するところで次のlineに分ける。
- `text`: 字幕。`\n` で意図した位置に改行できる。
- `voiceText`: 発音専用。省略時は `text` を読む。入力している場合、発言内容を変えるときは両方を直す。
- `speed` / `intonation` / `pause`: 省略すると `audio` の基本設定を使う。基本話速1.17、抑揚1.17、間0.35秒。
- `expressions`: 話していない側のリアクションも指定できる。省略時はずんだもん `listen`、めたん `proud`。

| ずんだもん | 四国めたん |
|---|---|
| `listen` 聞く | `proud` 得意げ |
| `explain` 指差し解説 | `talk` 話す |
| `proud` ドヤ顔 | `point` 指差し |
| `shocked` 驚き | `surprise` 驚き |
| `hungry` 食べたい | `troubled` 困り顔 |
| `dance` 喜ぶ | `whisper` ひそひそ |
| `apology` 謝る | `closed` 目を閉じる |
| `smile` 笑顔 / `greeting` 挨拶 | |

字幕は33pxを維持して最大2行に分割し、超えた分は次のページに送ります。ページ切り替えは音素同期ではなく文字数による時間配分です。テンポと読みやすさのため、1セリフは短めにし、長い説明を二人の会話へ分けてください。

## 制作の順序

1. `npm run doctor` で素材と環境を確認する。
2. `content/episode.json` を編集する。話題番号は1からの連番。
3. 新しい音声が必要ならVOICEVOXを起動して `npm run audio:dual`。画面だけの変更は `npm run sync`。
4. `npm run check` と `npm run preview` を実行する。
5. `out/review/index.html` を開き、全セリフとエンディングを目視する。字幕全体の切り替え・口パクは `npm start` で再生する。
6. 確認後、`npm run render`。成果物は `out/zundamon_metan.mp4`。

音声キャッシュは読み・話者・話速・抑揚と音声ファイルのハッシュを照合します。字幕・画像・表情だけの変更では再合成しません。変更されたセリフの音声がない場合、`sync` はそのIDを知らせて停止します。

音声はWAV自体から長さと音量を測り、話者交代・フレーム数・口パクを生成します。特定のシーン番号に話者の切り替え秒数を直書きしないでください。

## 絵と画面のルール

- 座標は `src/layout.ts`、色と文字サイズは `src/theme.ts`。素材の都合でその場しのぎの座標を増やさない。
- 中央画像は1720×770。明るいTVアニメ背景風で、文字・ロゴ・数字・人物キャラクターを描かない。
- 画像を追加・差し替えたら、`topics[].image` を変えて `npm run sync`。生成JSONの手編集は不要。
- 背景はぼかしと薄いベール。装飾を増やさず、説明・キャラ・字幕が競合しないようにする。
- けいフォントのロード失敗はエラーとして扱う。
- 音声・立ち絵・背景・BGMのクレジットを保つ。

## よくあること

| 状況 | 対応 |
|---|---|
| VOICEVOX未起動 | 既存音声で確認するならそのまま。新規合成時だけ起動する |
| 音声が未生成というエラー | `voiceText` 等を確認し、VOICEVOX起動後 `npm run audio:dual` |
| 文字が表示枠を超える | エラーに出た文章を短くして再プレビュー |
| PSDを置いても変わらない | 対応PSDを配置し `npm run characters` を実行する |
| 別作者・別キャラのPSDを使いたい | レイヤー名と抽出処理の対応が必要。置くだけで対応すると案内しない |
| 画像だけ直したい | `topics[].image` を変更して `npm run preview` |
| 短いテスト動画を見せたい | 「このシーンの確認用プレビュー。全編は別途」と明記する |

既存の徳島編は移行用サンプルです。新しいテーマの事実関係・素材の利用条件は制作時に確認してください。
