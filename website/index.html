AIを使わず、自分で環境を準備する場合

Node.js（18以上）とPython（3.9以上）を用意します。解凍したキットのフォルダをターミナルで開き、順に実行してください。

npm install
npm run doctor
npm start

ターミナルは、文字で操作するためのアプリです。起動したRemotion Studioで「DualExplainer」を選ぶと、見本を確認できます。

よくある質問

動画編集やプログラミングの経験がなくても使えますか？

画面の配置や字幕のデザインは準備済みです。まずは見本を動かし、AIに台本の変更を頼むところから始められます。ソフトのインストールや、ファイルを開く操作は必要です。

このサイトに文章を入れると、動画が完成しますか？

このページで作成できるのは「AIへの依頼文」です。動画の制作と保存は、ご自身のパソコンで行います。キットをダウンロードし、そのフォルダを編集・実行できるAI開発ツールで開いてください。文章の相談だけができるチャットの場合は、コマンドの実行などを自分で行う必要があります。

スマートフォンでも使えますか？

このサイトの閲覧、見本動画の再生、依頼文の作成はスマートフォンでもできます。動画を制作する手順は、MacまたはWindowsのパソコンを前提にしています。

費用はかかりますか？

このリポジトリはダウンロードして使えます。利用するAIツールや画像生成サービスには、別途料金がかかる場合があります。Remotionや各素材の利用条件・ライセンスは、提供元で確認してください。

Remotionのライセンスを確認する ↗
最初から画像や立ち絵を集める必要はありますか？

同梱された見本用素材で、最初の動作確認ができます。自分のテーマに合う画像へ変更するのは、そのあとで大丈夫です。別のキャラクターやPSDを使う場合は、素材に合わせた設定が必要です。

エラーが出て、先に進めません。

エラーの文章をコピーして、キットを開いているAIに「ここで止まりました。原因を確認して」と伝えてください。音声をつくるときはVOICEVOXが起動しているか、最初に確認しましょう。

台本の編集・コマンド・設定ファイル

番組名・セリフ・画像・表情は content/episode.json にまとめています。詳細はリポジトリのガイドへ。

制作ガイドを読む ↗
npm run audio:dual必要な音声をつくる
npm run preview全シーンの静止画を確認する
npm run render完成動画を書き出す

AI向け設定ファイルだけをダウンロード ↓
既存の制作環境へ設定を追加したい方向けです。このZIPだけでは動画制作はできません。

立ち絵をPSDから準備する方法

同梱PNGを使う場合、この作業は不要です。対応する坂本アヒル様のPSD（ずんだもん2.3 / 四国めたん2.1）をキットのフォルダに置き、Pythonの psd-tools と Pillow を用意してから npm run characters を実行します。

別作者・別キャラクターのPSDは、レイヤーに合わせた対応が必要です。詳しくはREADMEを確認してください。
